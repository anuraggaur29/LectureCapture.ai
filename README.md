# LectureCapture

AI-powered lecture notes generator. Upload any lecture recording and get beautifully structured notes with tables, diagrams, and flashcards.

## Features
- 🎙️ Audio transcription (Whisper)
- 🧹 Smart transcript cleaning (Gemini)
- 📊 Structured notes with tables & diagrams
- 🃏 Auto-generated revision flashcards
- 🌙 Dark mode
- 💾 Local storage (IndexedDB)
- 🌐 Works in Hindi + English

## Tech Stack
- **Frontend**: Vanilla HTML/CSS/JS
- **AI**: Puter.js (free, unlimited)
- **Storage**: IndexedDB (browser)
- **Hosting**: Netlify (static)

## Deploy

Just open `site/index.html` in your browser. No server needed.
